# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Что это за проект

Редизайн сайта **axelnn.ru** — интернет-магазин товаров для фигурного катания (Нижний Новгород).
Действующий сайт работает на Bitrix + шаблон Aspro Next. Здесь делается новая вёрстка с нуля,
а полная копия старого сайта лежит рядом как донор контента и референс.

Два независимых слоя:

| Слой | Где | Что это |
| --- | --- | --- |
| **Новый сайт** | `index.html`, `assets/` | Статика, которую мы пишем. Пока только главная страница |
| **Донор** | `old_version/site/` | Зеркало живого axelnn.ru (607 HTML, ~2500 фото). Только читаем |
| **Скрипты выгрузки** | `tools/*.mjs` | Краулер и парсеры, которыми донор был получен |

**Главная задача — редизайн.** Пишем новый сайт; `old_version/` только читаем как источник
контента и как референс «что было». Ничего в нём не редактируем и не переносим вёрстку Aspro.

Донор докачан **не полностью** — часть страниц и фото ещё подтягивается (`fetch-missing.mjs`).
Отсутствующий файл в `old_version/site/` — это не поломка, а незавершённая выгрузка: структура
каталогов и формат данных уже финальные и не изменятся, добавляется только содержимое.

Сборки нет: ни `package.json`, ни зависимостей, ни бандлера. Чистый HTML + CSS + inline vanilla JS.
Скрипты в `tools/` — ESM на голой стандартной библиотеке Node (нужен Node ≥ 18 ради глобального `fetch`).

## Команды

```bash
# Новый сайт
node tools/serve.mjs                 # http://127.0.0.1:4173

# Копия старого сайта — пути внутри HTML абсолютные (/upload/, /bitrix/),
# поэтому нужен сервер с корнем именно в site/
node tools/serve.mjs --root old_version/site --port 8080
```

**Python в системе не установлен** — `python -m http.server` не сработает.
`serve.mjs` написан на голом `node:http` и заодно экспортирует `startServer()`,
которым пользуются `shot.mjs` и `audit.mjs`.

### Конвейер выгрузки (`tools/`)

Порядок важен, каждый шаг дописывает результат предыдущего:

```bash
node tools/crawl.mjs            # обход axelnn.ru -> old_version/site/ + _crawl-state.json
node tools/verify.mjs           # ищет ссылки без файла на диске -> _missing.json
node tools/fetch-missing.mjs    # докачивает всё из _missing.json
node tools/extract-products.mjs # парсит зеркало -> products.json, categories.json, products.md
```

`crawl.mjs` и `fetch-missing.mjs` **инкрементальны**: файл уже на диске — не перекачивается.
Повторный прогон безопасен и дёшев. Цикл `verify → fetch-missing → verify` гоняем, пока
«не хватает» не станет нулём.

Артефакты `products.json`, `categories.json`, `products.md`, `_crawl-state.json`, `_missing.json` —
генерируемые. Сейчас их в репозитории нет: если нужны данные товаров, запусти
`extract-products.mjs` (зеркало уже скачано, повторный краул не нужен). Формат `products.json`
описан в [old_version/README.md](old_version/README.md).

## Устройство `tools/`

Все четыре скрипта дублируют друг у друга три вещи — при правке одной правь во всех:

- **Windows-путь из `import.meta.url`**: `new URL(u, import.meta.url).pathname.replace(/^\/([A-Za-z]:)/, '$1')` —
  срезает ведущий слэш у `/C:/...`. Без этого ничего не найдётся на диске.
- **`toPath(url)`** — url → путь на диске: `/` → `index.html`, экранирование запрещённых в Windows
  символов, обрезка точек/пробелов в конце сегмента (NTFS их не хранит).
- **`SKIP_RE`** — чёрный список: корзина, авторизация, фильтры, сортировки, utm. Держит краулер
  от бесконечного обхода фасетных ссылок Bitrix.

`extract-products.mjs` определяет карточку товара эвристикой: `itemprop="price"` **и**
маркер детальной страницы Aspro (`element_detail_text` / `JCCatalogElement`). Всё остальное
в `/catalog/` c `<h1>` считается разделом, прочее — информационной страницей.
Парсинг регулярками, без DOM-библиотек.

## Устройство нового сайта

- **Токены** — CSS-переменные в `:root` в начале [assets/css/style.css](assets/css/style.css).
  Фирменный цвет `--teal: #1690A0`, текст `--ink`, серые заливки `--grey`/`--canvas`.
- **Именование** — BEM: `.card`, `.card__media`, `.card__name--block`.
- **Шрифты** — Montserrat (интерфейс) + Playfair Display (заголовки, логотип), с Google Fonts.
  Заголовки — всегда uppercase + `clamp()` для размера.
- **Адаптив** — без медиазапросов: всё на `clamp()`, `auto-fill` гридах и `flex-wrap`.
  Новые блоки делай так же, не добавляй брейкпоинты без нужды.
- **`.ph`** — плейсхолдер вместо фото. Когда появляется настоящая картинка,
  `<span class="ph"></span>` заменяется на `<img class="ph" src="..." alt="...">`
  (класс сохраняется, стили рассчитаны на оба тега).
- **JS** — единственный inline-скрипт в конце `index.html`: листалка каруселей.
  Отдельного js-файла нет и пока не нужно.
- **Ссылки в шапке/подвале/карточках ведут на боевой `https://axelnn.ru/...`** — это заглушки,
  внутренних страниц нового сайта ещё не существует.

Фото товаров для новых блоков берём из `old_version/site/upload/iblock/` (оригиналы),
тексты — из `products.json` или напрямую из HTML в `old_version/site/`.
