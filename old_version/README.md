# old_version — копия сайта axelnn.ru (донор для редизайна)

Выгрузка действующего сайта **[axelnn.ru](https://axelnn.ru/)** (Bitrix + шаблон Aspro Next),
интернет-магазин товаров для фигурного катания.

Дата выгрузки: **20.07.2026**

## Что выгружено

| | |
|---|---|
| Товаров | **1416** — все с названием, ценой, категорией и описанием |
| Фотографий товаров | **4005** оригиналов (все проверены — лежат на диске) |
| Страниц каталога | 95 разделов и подразделов |
| Прочих страниц | 30 (доставка, оплата, о компании, контакты, FAQ…) |
| Всего файлов | 12 144 |
| Объём | 1.8 ГБ |

## Что здесь лежит

| Путь | Что это |
|---|---|
| `site/` | Зеркало сайта с оригинальными путями: HTML, CSS, JS, шрифты, изображения |
| `products.json` | Данные всех товаров — машиночитаемо, для переноса в новый шаблон |
| `products.md` | Те же товары в читаемом виде — удобно листать глазами |
| `categories.json` | Разделы каталога + список прочих страниц |
| `_product-urls.json` | Все найденные адреса карточек (в т.ч. 41 битая — см. ниже) |
| `_missing.json` | Отчёт сверки: чего не хватает после последней проверки |
| `_crawl-state.json` | Технический лог краулера |

## Как открыть копию сайта локально

Пути внутри HTML абсолютные (`/upload/…`, `/bitrix/…`), поэтому нужен локальный
сервер с корнем в `site/` — двойным кликом по файлу вёрстка не соберётся.

```bash
node tools/serve.mjs --root old_version/site --port 8080
# затем http://127.0.0.1:8080/
```

Проверено: главная, каталог, карточки товаров, фото, CSS (1 МБ) и JS (700 КБ) отдаются.
Динамика (корзина, фильтры, поиск, авторизация) не работает — это статический слепок.

## Формат `products.json`

```jsonc
{
  "site": "https://axelnn.ru",
  "exported": "2026-07-20",
  "count": 1416,
  "products": [
    {
      "id": "21804",                     // артикул
      "name": "Фигурные коньки Edea TEMPO SET BALANCE",
      "url": "https://axelnn.ru/catalog/…",       // адрес на живом сайте
      "localFile": "site/catalog/…/index.html",   // страница в этой копии
      "category": "Фигурные коньки/Коньки Edea",
      "brand": "Edea",
      "price": 21500,                    // минимальная цена
      "priceMax": 21500,                 // максимальная (если зависит от размера)
      "oldPrice": null,                  // цена до скидки
      "currency": "RUB",
      "available": true,
      "offerCount": 3,                   // сколько торговых предложений
      "stickers": ["Новинка"],           // метки на карточке
      "sizes": ["205", "215", "225"],
      "variants": {},                    // прочие варианты (цвет и т.п.)
      "mainImage": "/upload/iblock/c17/….jpg",
      "images": ["/upload/iblock/…"],    // все фото товара, оригиналы
      "description": "Фигурные коньки Edea Tempo с лезвиями…",  // чистый текст
      "descriptionHtml": "<p>…</p>"      // то же с абзацами и списками
    }
  ]
}
```

Пути в `images` — от корня `site/`. Фото `/upload/iblock/c17/xxx.jpg`
физически лежит в `old_version/site/upload/iblock/c17/xxx.jpg`.

## Что нужно знать про эти данные

- **41 карточка недоступна.** В каталоге сайта остались ссылки на удалённые товары —
  они отдают 404. Список в `_product-urls.json` → `missing`. Скачано всё живое: 1424 адреса,
  из них 1416 распознались как карточки товара.
- **Структурированных характеристик на сайте нет.** Параметры (жёсткость, материал,
  производитель) вписаны прямо в текст описания. При редизайне их придётся либо
  разбирать из текста, либо заводить заново.
- **Размеры есть у 913 товаров** — у остальных товар без размерной сетки.
- **Цены — на дату выгрузки.** Перед запуском нового сайта сверить с актуальными.

## Как это использовать в редизайне

- **Контент товаров** — из `products.json`, переносим в новый шаблон без копипаста.
- **Фотографии** — из `site/upload/iblock/` (оригиналы в максимальном разрешении).
- **Тексты информационных страниц** — из `site/info/`, `site/help/`, `site/company/`.
- **Старая вёрстка** — как референс: что сохранить, что выкинуть.

## Инструменты (`../tools/`)

| Скрипт | Что делает |
| --- | --- |
| `crawl.mjs` | Краулер: обход по ссылкам + sitemap, качает страницы и ассеты |
| `extract-products.mjs` | Парсит карточки → `products.json` / `products.md` |
| `product-urls.mjs` | Собирает все адреса карточек, показывает нескачанные |
| `verify.mjs` | Сверяет: всё ли, на что ссылаются страницы, есть на диске → `_missing.json` |
| `fetch-missing.mjs` | Докачивает по отчёту сверки |
| `cleanup.mjs` | Удаляет дубли-страницы (`?oid=`, сортировки). `--dry` — примерка |
| `serve.mjs` | Локальный сервер для просмотра копии |

Повторный запуск не перекачивает уже сохранённое — можно догружать инкрементально:

```bash
node tools/crawl.mjs            # обход и загрузка
node tools/cleanup.mjs          # выкинуть дубли
node tools/verify.mjs           # что не долетело
node tools/fetch-missing.mjs    # добрать
node tools/extract-products.mjs # пересобрать данные товаров
```
