# old_version — копия сайта axelnn.ru (донор для редизайна)

Полная выгрузка действующего сайта **https://axelnn.ru** (Bitrix + шаблон Aspro Next),
интернет-магазин товаров для фигурного катания.

Дата выгрузки: **20.07.2026**

## Что здесь лежит

| Путь | Что это |
|---|---|
| `site/` | Зеркало сайта с сохранением оригинальных путей: HTML, CSS, JS, шрифты, все изображения |
| `products.json` | Структурированные данные всех товаров (машиночитаемо) |
| `products.md` | Те же товары в читаемом виде — удобно листать глазами |
| `categories.json` | Разделы каталога + список прочих страниц (инфо, доставка, контакты…) |
| `_crawl-state.json` | Технический отчёт краулера: список URL и ошибки |

## Как открыть копию сайта локально

Пути внутри HTML — абсолютные (`/upload/...`, `/bitrix/...`), поэтому просто открыть файл
двойным кликом мало: нужен локальный сервер с корнем в `site/`.

```bash
cd old_version/site
python -m http.server 8080
# затем http://localhost:8080/
```

Динамика (корзина, фильтры, поиск, авторизация) работать не будет — это статический слепок.
Вёрстка, стили, шрифты и картинки — на месте.

## Структура `site/`

```
site/
├── index.html                  главная
├── catalog/                    каталог
│   └── <раздел>/
│       ├── index.html          страница раздела
│       ├── <подраздел>/
│       └── <ID>/index.html     карточка товара
├── info/ help/ company/
├── services/ contacts/ sale/   информационные страницы
├── upload/
│   ├── iblock/                 оригиналы фотографий товаров
│   └── resize_cache/           превью и уменьшенные копии
└── bitrix/                     CSS, JS, шрифты, иконки шаблона
```

## Формат `products.json`

```jsonc
{
  "site": "https://axelnn.ru",
  "count": 000,
  "products": [
    {
      "id": "21804",                    // артикул
      "name": "Фигурные коньки Edea TEMPO SET BALANCE",
      "url": "https://axelnn.ru/catalog/...",   // оригинальный адрес
      "localFile": "site/catalog/.../index.html", // страница в этой копии
      "brand": "Edea",
      "price": 21500,                   // минимальная цена
      "priceMax": 24000,                // максимальная (если цена зависит от размера)
      "oldPrice": null,                 // цена до скидки
      "currency": "RUB",
      "available": true,
      "breadcrumbs": ["Главная", "Каталог", "..."],
      "category": "Каталог / Коньки Edea",
      "sizes": ["205", "215", "..."],   // размерная сетка
      "variants": {},                   // прочие варианты (цвет и т.п.)
      "properties": {},                 // характеристики
      "mainImage": "/upload/iblock/.../photo.jpg",
      "images": ["/upload/iblock/..."], // оригиналы фото — ищи их в site/upload/
      "imagesResized": [],              // крупные превью
      "description": "Текст описания товара…"
    }
  ]
}
```

Пути в `images` — от корня `site/`. То есть фото
`/upload/iblock/c17/xxx.jpg` физически лежит в `old_version/site/upload/iblock/c17/xxx.jpg`.

## Как это использовать в редизайне

- **Контент товаров** (названия, описания, цены, размеры, фото) берём из `products.json` —
  переносим в новый шаблон без ручного копипаста.
- **Фотографии** — из `site/upload/iblock/` (оригиналы в максимальном разрешении).
- **Тексты информационных страниц** — из `site/info/`, `site/help/`, `site/company/`.
- **Старая вёрстка** — как референс структуры и того, что нужно сохранить/выкинуть.

## Инструменты

Скрипты выгрузки лежат в `../tools/`:

- `crawl.mjs` — краулер (обход по ссылкам + sitemap, скачивает страницы и ассеты)
- `extract-products.mjs` — парсер карточек товаров в `products.json` / `products.md`

Повторный запуск не перекачивает уже сохранённые файлы — можно догружать инкрементально:

```bash
node tools/crawl.mjs
node tools/extract-products.mjs
```
