# Аксель·НН — сайт и админка

Интернет-магазин товаров для фигурного катания, Нижний Новгород.
Статический сайт + админка, через которую владелец правит его сам.

Подробное устройство — в [CLAUDE.md](CLAUDE.md). Инструкция владельцу сайта —
в [admin/README.md](admin/README.md). Как выложить на боевой хостинг —
в [deploy/README.md](deploy/README.md).

## Быстрый старт

```bash
npm install          # один раз: sharp, playwright-core (нужны инструментам, не сайту)
npm run admin        # админка и сайт: http://127.0.0.1:4180/admin/
```

При первом запуске в консоли появится логин `admin` и случайный пароль — их же можно
поменять: `node admin/server.mjs --set-password`.

Только сайт, без админки: `npm run serve` → http://127.0.0.1:4173

## Что где лежит

| Папка | Что это |
| --- | --- |
| `index.html`, `catalog/`, `company/`, `help/`, … | страницы сайта |
| `assets/` | стили, скрипты, картинки |
| `content/` | данные, которые правит владелец: товары, разделы, контакты |
| `admin/` | админка: сервер и интерфейс |
| `tools/` | сборка сайта: генераторы страниц, сервер, скриншоты, аудит |
| `tools/donor/`, `old_version/` | архив эпохи переноса со старого сайта, для работы не нужен |

## Как это работает

Сайт статический: все страницы лежат готовыми файлами, никакого бэкенда нет.
Товары, тексты и контакты хранятся в `content/*.json`, а страницы **собираются**
из них генераторами.

```
content/*.json  ──►  build-pages ──► build-catalog ──► build-products  ──►  готовые HTML
   (правит                тексты        меню, витрина,      1142 страницы
   владелец)              и контакты    разделы             товаров
```

Поэтому между правкой и сайтом есть шаг публикации. В админке это кнопка
«Опубликовать», в терминале — `npm run build`. **Порядок трёх шагов менять нельзя:**
шапка и подвал живут в `index.html`, и следующий шаг всегда берёт результат предыдущего.

## Частые задачи

```bash
npm run build                  # пересобрать сайт целиком
npm run admin                  # поднять админку
node tools/audit.mjs /catalog/ # проверить вёрстку страницы на 4 ширинах
node tools/shot.mjs / --full --w 1440   # скриншот страницы целиком
```

`shot.mjs` и `audit.mjs` запускай **из PowerShell**: Git Bash переписывает путь
с ведущим слэшем и вместо нужной страницы открывает главную.

## Публикация

Репозиторий — GitHub Pages (`Silva2122.github.io`), сайт публикуется из ветки `master`.

- Из админки: галочка «Сразу отправить на GitHub» в разделе «Публикация» — она делает
  коммит и `git push` после сборки.
- Руками: `npm run build`, затем обычные `git add -A && git commit && git push`.

## Правила разработки

- Данные не правим руками в `assets/products.json` — он собирается из `content/`.
- Внутри маркеров `<!-- ОБЩЕЕ:… -->` и `<!-- КАТАЛОГ:МЕНЮ -->` руками не правим:
  перезапишется генератором. Источник шапки и подвала — `index.html`.
- Комментарии и тексты — по-русски.
